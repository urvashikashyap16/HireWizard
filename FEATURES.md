## 🚀 **HOW TO RUN**

**3 Simple Steps:**

1. **Install dependencies:**
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

2. **Run server:**
   ```bash
   python app.py
   ```

3. **Open browser:**
   ```
   http://localhost:5000
   ```

**DONE! App is running!** 🎉
